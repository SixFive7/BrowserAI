# The numbers index -- every number the product tunes, and where it came from

**Decided 2026-10-08 and built 2026-10-09.** The maintainer's question of
2026-10-07, verbatim: *"Maybe we should start tracking all magical numbers used in
this project in an index of sorts so that we can at a later date re-check the data by
using the provenance of these records to re-determine if the number is still
accurate?"*, and his answer to the options the next day: *"f3 a"*. The options, and
why the others were not taken, are F3 in
[the one-binary design](../docs/design/one-binary/README.md#f3-the-numbers-index).
With R he asked for the clients' limits to join it, in his words of 2026-10-08:
*"About the timeouts: Do all these timeouts work within both the claude or codex
timeouts? And if they differ do the timeouts differ? Add them to our numbers list we
discussed earlier."*

**An index, not a measurement article.** A measured number links the entry that holds
the measurement, and that entry carries the marker, the versions and the procedure the
[conventions](README.md#conventions) ask of it. A row here says which member the code
reads, what it governs and where its value came from, so that somebody can check it
again without first finding the code, and without trusting a number nobody can trace.

## What a row says

- **Symbol** -- the member the code reads, as `Type.Member`.
- **Value** -- what the member holds: a duration in `ms`, `s`, `min`, `h` or `d`, a
  size in bytes, `KiB` or `MiB`, and anything else as a plain number.
- **Governs** -- what in the product waits on it, stops at it or is cut at it, and the
  member of the owner that reads it.
- **Kind** -- one of four, in bold at the start of the cell:
  - **Measured** -- the number is a measurement.
  - **Derived** -- computed from other rows here, which the cell names.
  - **Chosen** -- a judgement. The evidence says what it was weighed against, and
    where it was weighed against nothing, the evidence says that.
  - **Upstream** -- set by somebody else's code, a client, a library or Windows, and
    read or measured here.
- **Evidence** -- what the number rests on.
- **Established** -- when the value was measured, read or decided, and the versions it
  held under. Where the code says nothing about when, it is the day the line that
  holds the value was written, from `git blame`.
- **Re-check** -- what to read or run to establish it again. A judgement that rests on
  no measurement has nothing to re-run, and the cell says so.

## What holds it

`NumbersIndexTests` holds this page and the code against each other on every build:

- every number in a **named class** -- `SessionTimes`, `ProcessBounds`,
  `UpdateBudgets`, `RelayConstants`, `ClientLimits` and `WordingTimes` -- has a row
  here with its value;
- every row names a member that exists, in a named class or in the type that owns it,
  and the member holds the value the row says;
- every row says its kind, when it was established and how to check it again, and
  every line of a table here is one the test can read;
- every wait a tool call can meet ends inside the stricter client's limit on one call,
  which is the table in [the first call](../docs/design/one-binary/README.md#the-first-call)
  that the maintainer answered *"r ok"*;
- and **no literal duration lives anywhere else in the product's source**. A scan of
  every `.cs` file under `src/` outside the six named classes refuses a `TimeSpan`
  built from a number, a wait or a cancellation handed a number, a constant, property
  or local named for a unit and given a number, a back-off capped at a number, and a
  date moved by a number. Zero is let through, because it is not a duration anybody
  tunes, and so is a Win32 error code whose name ends in a unit, such as
  `ERROR_SEM_TIMEOUT`.

**What the scan does not see, stated so that nobody reads it as seeing it:** an elapsed
time compared against a number through `TotalMinutes`, `TotalHours` or `TotalDays`,
which is how a sentence picks its unit in `SessionManager` and in
`BrowserProvisioner`; a duration inside a string literal, the page's own script
included, whose countdowns are redrawn every 1,000 ms by `setInterval` in
`PageAssets`; and every number that is not a duration. The sizes, counts and lengths
at the end of this page are here because they are tunable, and nothing makes a new
one arrive.

**Not here, on purpose:** protocol and schema versions, Win32 and SQLite codes and
structure sizes, Windows' own limits such as `MAX_PATH` and the longest due time a
timer takes, and every number in the suite. Each is fixed by what it describes, and
nobody tunes it.

## Adding a number

Declare it in the named class it belongs to, with a summary that names the member
that reads it, and give the owner a member whose value is the named one, so that the
code reading it does not move and the owner's remarks go on saying why. Add its row
here in the same commit; the build is red until both exist. A number that is not a
duration may stay where it is, and still gets a row when it is tunable.
