BrowserAI gives an AI agent a real browser on Windows. It is one program now, and it runs in the background from the moment you sign in. It holds every session, so a session outlives the client that drove it. A Start Menu click opens its dashboard in your own browser. BrowserAI registers itself with Codex as well as Claude Code.

Since 2026-09-30 Claude Code opens its connections a new way, and 1.1.0 gave those connections no BrowserAI tools. This version fixes that. It also removes the configuration window, where clicking a link planted in a project file could run something.

A project's `.mcp.json` that names `BrowserAI.Server.exe` has to be set up again from the dashboard. A copy installed outside `%LocalAppData%\BrowserAI.app` sets nothing up: uninstall it and run the installer again without `--installto`. For an agent, `browserai_init` and `browserai_resume` require four settings, `browserai_catch_up` requires a `why`, `tracing` is `transcript`, `browserai_set_purpose` is `browserai_change_purpose`, and an argument a tool does not have is refused.
