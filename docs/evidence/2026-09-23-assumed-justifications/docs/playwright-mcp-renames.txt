ENTRY 3 -- "upstream renamed one of its own tools inside four months" (DECISIONS.md:700)
MEASURED 2026-09-23 from npm's own published tarballs. Rig: pwmcp-registry.json (the full
registry document, 435 versions), pwmcp/*.tgz (27 tarballs), pwmcp-toolnames.json (the
extracted name sets). Names were read out of each package's lib/tools/*.js by matching
name: '<literal>' inside the tool definitions, and every pairing below was then confirmed
by locating the DEFINING FILE in both versions, so a rename is not inferred from a
set difference alone.

First published release: 0.0.1 on 2025-03-21T20:27:05Z. (A 1.52.0-alpha train exists from
2025-03-13; the four-month clock is taken from the first non-alpha.)

RENAME EVENT 1 -- 0.0.9 (2025-04-01) -> 0.0.10 (2025-04-06): NINE tools renamed in one
release, 16 DAYS after 0.0.1 and 5 days after 0.0.9.
  lib/tools/screenshot.js became lib/tools/screen.js and every name in it moved:
    browser_screenshot      -> browser_screen_capture
    browser_click   (vision)-> browser_screen_click
    browser_drag    (vision)-> browser_screen_drag
    browser_move_mouse      -> browser_screen_move_mouse
    browser_type    (vision)-> browser_screen_type
  lib/tools/common.js was split and four names moved with the split:
    browser_choose_file     -> browser_file_upload     (lib/tools/files.js)
    browser_go_back         -> browser_navigate_back   (lib/tools/navigate.js)
    browser_go_forward      -> browser_navigate_forward(lib/tools/navigate.js)
    browser_save_as_pdf     -> browser_pdf_save        (lib/tools/pdf.js)

RENAME EVENT 2 -- 0.0.22 (2025-05-07) -> 0.0.24 (2025-05-12): the single cleanest one,
47 days after 0.0.1. Same file, same binding, same capability -- only the name moved:
    0.0.22 package/lib/tools/common.js: const wait = captureSnapshot => defineTool({
             capability: 'wait', schema: { name: 'browser_wait', title: 'Wait', ... } })
    0.0.24 package/lib/tools/common.js: const wait = captureSnapshot => defineTool({
             capability: 'wait', schema: { name: 'browser_wait_for', title: 'Wait for', ... } })

LATER, OUTSIDE THE WINDOW, recorded so the trend is not overstated from two points:
  0.0.30 (2025-07-14) -> 0.0.31 (2025-07-17) withdrew browser_generate_playwright_test and
  the whole browser_screen_* family, adding browser_evaluate and browser_mouse_*_xy. Those
  are withdrawals and replacements rather than pairings, and are not counted as renames.

THE NUANCE THE ROW SHOULD CARRY: browser_take_screenshot, which the row names as the key a
deny hook is written against, is one of the names that DID survive -- it is defined in
lib/tools/snapshot.js in 0.0.9 and in 0.0.10 and is still in the surface today. So the hook
example is an illustration of the risk and not an instance of it; what was actually renamed
was the vision-mode sibling browser_screenshot.
