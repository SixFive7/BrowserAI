Every option of the MCP server command against what BrowserAI does with it.

Command line BrowserAI actually passes (src/BrowserAI/Runtime/ChildLaunch.cs:147-160):
    <payload>\node\node.exe  <payload>\mcp\node_modules\@playwright\mcp\cli.js  --config <file>  --sandbox
Nothing else. Merge order in the child is config file -> environment -> CLI
(see config-resolution.txt, resolveCLIConfigForMCP).

53 options are declared. 1 is -V/--version, 2 are hidden (--remote-header, --vision),
--sandbox and --no-sandbox share one attribute. So 49 distinct settings.

KEY  SET     = BrowserAI writes the equivalent config key.
     DIFF    = writes it deliberately to something other than upstream's default,
               or writes upstream's default deliberately so it is on the record.
     NOT SET = never written and never passed.
     REFUSED = also blocked on the environment route, ChildEnvironment.Refused,
               src/BrowserAI/Protocol/ChildEnvironment.cs:227-268.
