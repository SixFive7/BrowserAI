test in this repository can see it if it does not:

- **33 `<li>` elements, and all 33 carry a `<strong>` and a `read more` `<a href>`.**

125,000 characters, GitHub's; this body is 7,477 bytes. The fallback that drops
the per-entry links is a pathological path, not a second design.
