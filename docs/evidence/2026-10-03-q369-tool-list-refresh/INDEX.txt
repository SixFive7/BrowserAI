RIG (rig\)
  phserver.js     the stub MCP server. Answers tools/list with ONE tool, update_in_flight, while "updating";
                  the real list (browserai_init, browserai_list) after. Declares tools.listChanged or not
                  (PH_CAP). Becomes real on a file (PH_DONE_FILE) or a timer (PH_DONE_AFTER_CALL_MS), and
                  can then send list_changed (PH_NOTIFY_ON_DONE). Per-launch modes (PH_MODES), a self-kill
                  after the Nth call or on initialize (TerminateProcess, exit 1, as an apply's kill pass
                  ends a server; PH_KILL_MODE=clean is the exit-0 control), and list_changed right after
                  notifications/initialized from chosen launches (PH_NOTIFY_AFTER_INIT[_DELAY_MS]).
                  Writes <run>\ph.launches.log and <run>\ph.wire.jsonl (every frame, with launch and pid).
  ccmodel.js      scripted Anthropic Messages API stub; stateless policy re-read from a per-run policy
                  file; captures every request body (model.requests.jsonl) and a digest (model.seen.jsonl:
                  which browserai tools were offered, what the "model" did, every browserai result).
                  Loads deferred tools through ToolSearch when tool search is on.
  cxmodel.js      the same for the OpenAI Responses API (Codex), namespace-aware.
  ExitRig\        copy of .work\client-exit's harness, plus steps touch / rm / waitFile / snap and a raw
                  pseudoconsole capture (pty-raw.bin) for screen rendering. Built into rig\bin.
  appdrv.js       copy of .work\client-behaviour's app-server driver.
  gen.js          Claude Code batches: P = claude -p, S = stream-json with the VS Code extension's env
                  (CLAUDE_CODE_ENTRYPOINT=claude-vscode, MCP_CONNECTION_NONBLOCKING=true, ...) and its
                  control requests (mcp_status, mcp_reconnect, mcp_toggle, as extension.js sends them).
  gen-tui.js      Claude Code interactive UI in a pseudoconsole (no window), /mcp driven by keystrokes.
  cx-batch.js     Codex batches: codex exec (+ exec resume --last) and codex app-server, clean env.
  summarize.py / table.py / cxtable.py / render.py (pyte, installed into pylib\) / offsets.py / g.py
