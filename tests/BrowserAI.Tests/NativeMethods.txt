// THE LAYOUT ORACLE'S INPUT, AND IT IS DELIBERATELY SHORT.
//
// Microsoft.Windows.CsWin32 generates a declaration for every name in this
// file, from Windows' own metadata. Nothing here is used by the product --
// BrowserAI hand-writes its interop and the decision not to adopt CsWin32 is
// recorded in TODO.md. These seven structs exist so InteropLayoutTests can
// compare the hand-written definitions against Microsoft's, which is the only
// thing in this repository that checks them against the vendor and not
// against the last person who read the header.
//
// ONLY STRUCTS. No functions: a generated P/Invoke would be a second way to
// call Windows sitting in the test assembly, and the point of the oracle is to
// check the declarations we ship, not to provide an alternative to them.
//
// AND NOT EVERY STRUCT, SAID HERE AND NOT LEFT TO BE REDISCOVERED.
// NativeFile.Overlapped is hand-written and checked, but its
// oracle is System.Threading.NativeOverlapped and not this file: CsWin32
// refuses the name outright -- `error PInvoke003: This API will not be
// generated. Use System.Threading.NativeOverlapped instead`, measured
// 2026-08-24 -- so adding OVERLAPPED below turns the build red instead of
// producing a comparison. InteropLayoutTests says the same thing where the
// substitution is made.
//
// Adding a name here is cheap; adding one and not asserting on it is how this
// file becomes a dependency nobody can justify. Every name below is asserted.
//
// AND FOUR COM INTERFACES SINCE 2026-09-25, added by addition: the Task
// Scheduler's ITaskService, ITaskFolder, IRegisteredTask and IRunningTask, which
// the product declares by hand through [GeneratedComInterface] for the per-user
// logon task (Q282 a). They are types and not functions, so the rule above holds:
// nothing here calls them, and InteropLayoutTests reads each one's GUID, its
// methods' order and their arity by reflection and compares the product's slots
// with them. VARIANT is NOT here: CsWin32 refuses it in COM interface mode --
// `error PInvoke003: This API will not be generated. Use object instead of VARIANT
// when in COM interface mode`, measured 2026-09-25 -- so the hand-written VARIANT's
// oracle is the framework's own ComVariant, the way OVERLAPPED's is
// NativeOverlapped.
